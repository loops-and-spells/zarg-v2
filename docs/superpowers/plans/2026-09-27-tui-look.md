# TUI Redesign, Plan 1: The Look — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The shell looks like the approved redesign — theme tokens, headed blocks instead of nested frames, `○`/`●` selection, the agents rail, a one-line bar, a quiet status line, restyled popovers and panels, clean names — while the focus model (view or zarg's sheet) stays as it is.

**Architecture:** `@zarg/view` gains the theme (`THEME` tokens and `toneColor`), portable data every platform can read. `@zarg/view-tui` gets small pure helpers (`fit`, `heading`, `gauge`, `keyGlyphs`, `railRows`, `displayName`) that the renderers and `App` use, so the look is testable without frames; the renderers and `App` are restyled on top of them. Plan 2 (grid, review, palette, back stack, cards) builds on this.

**Tech Stack:** Bun (`mise x -- bun`), TypeScript, React 19, opentui 0.5.12.

**Spec:** `docs/superpowers/specs/2026-09-27-tui-redesign-design.md` (sections 1 and 2's rail, bar, popovers; plan 2 does the focuses, the palette and section 3).

## Global Constraints

- `mise run verify` before every commit; tools through `mise x -- bun …`.
- `@zarg/view`'s `.` export imports only `effect`; view-tui and client never import `@zarg/core` or `/server`.
- Truecolor, plain Unicode only (no Nerd Font glyphs).
- Theme tokens, exactly: `bg #0f1115`, `raised #161a21`, `line #262b35`, `text #d7dce2`, `dim #6b7280`, `faint #3b4150`, `accent #7aa2f7`, `attention #e0af68`, `ok #9ece6a`, `error #f7768e`, `selection #1f2533`.
- Tones to tokens: `normal → text`, `ok → ok`, `warn → attention`, `error → error`, `dim → dim`, `accent → accent`.
- Borders only on grid cards (plan 2), popovers and the palette (plan 2); never a box in a box.
- Glyphs: `⠼` running (braille spinner), `✓` done, `✗` failed, `■` stopped, `◆`/`◇` attention, `⚑` flagged, `━` gauges, `▸`/`▾` folds, `›` picker and input, `○`/`●` selectable/selected, `▍` cursor gutter.
- Names: no plugin prefix (`rehearse:`), no view key (`@status`) on screen; rows and lines never wrap, overlong text ends in `…` (the `text` section kind alone wraps words).
- Rail: 24 columns, `raised`; under 100 columns 3 columns (glyphs), `alt+a` unfolds it over the focus.
- Never start a core or the TUI in the repo root; no live models.

## Review Focus

1. A 200-character agent title or table cell at 80 columns: cut with `…` at the end, the row still one line, nothing pushed off-screen. → Task 2, test "`fit` cuts at the end and never wraps"; Task 3, test "a long cell ends in … on one line".
2. A tab title that equals another section's title (two `Findings`): the heading still shows which tab is current. → Task 3, test "the current tab is marked in the heading".
3. An agent with no plugin prefix (an RLM `rlm-12`, zarg): the rail and titles show a sensible name (`driver rlm-12`, `zarg`), never an empty string. → Task 4, test "`displayName` for RLMs, plugin agents and zarg".
4. A selectable table with no rows: no gutter marks, `nothing yet` in dim, no crash on Space. → Task 3, test "an empty selectable table".
5. Key hints whose names have no glyph (`X`, `D`, `PgUp PgDn`): shown as typed, never dropped. → Task 2, test "`keyGlyphs` keeps keys it has no glyph for".

```ts
/** zarg's one theme: the colours every platform draws with. Plugins name tones, never colours. */
export const THEME = { bg: "#0f1115", raised: "#161a21", line: "#262b35", text: "#d7dce2", dim: "#6b7280", faint: "#3b4150", accent: "#7aa2f7", attention: "#e0af68", ok: "#9ece6a", error: "#f7768e", selection: "#1f2533" } as const
export type ThemeToken = keyof typeof THEME
const TONE: Readonly<Record<string, ThemeToken>> = { normal: "text", ok: "ok", warn: "attention", error: "error", dim: "dim", accent: "accent" }
export const toneToken = (tone: unknown): ThemeToken => (typeof tone === "string" ? (TONE[tone] ?? "text") : "text")
export const toneColor = (tone: unknown) => THEME[toneToken(tone)]
```

```ts
export const fit = (text: string, width: number) => {
  const one = text.replace(/\s*\n\s*/g, " ")
  if (width <= 0) return ""
  return one.length > width ? `${one.slice(0, width - 1)}…` : one
}
export const heading = (title: string, width: number) => {
  const t = fit(title, width)
  const room = width - t.length
  return { title: t, rule: room > 1 ? ` ${"─".repeat(room - 1)}` : "" }
}
export const gauge = (done: number, total: number, width: number) => {
  const d = total > 0 ? Math.max(0, Math.min(width, Math.round((done / total) * width))) : 0
  return { done: "━".repeat(d), rest: "━".repeat(width - d) }
}
const GLYPH: Readonly<Record<string, string>> = { Enter: "⏎", Esc: "esc", Tab: "⇥", Space: "␣" }
export const keyGlyphs = (keys: string) => GLYPH[keys] ?? keys
```

### Task 3: Section renderers restyled

**Files:** Modify `packages/view-tui/src/sections.tsx` (every leaf, `AgentView`); test `packages/view-tui/test/sections.test.tsx` (rewrite expectations).

**Interfaces — Consumes:** Task 1 (`THEME`, `toneColor`), Task 2 (`fit`, `heading`, `gauge`). **Produces:** `AgentView` props unchanged; `TONES` removed (callers use `toneColor` / `THEME`); a `Heading` component exported:
```ts
export const Heading = (p: { readonly title: string; readonly width: number; readonly focused: boolean; readonly tabs?: ReadonlyArray<{ readonly label: string; readonly current: boolean }> }) => JSX.Element
```

The new look, per leaf:
- **Section frame:** no border. Each section is a `Heading` (bold title, `accent` when the section has focus, else `dim`; then a `faint` rule), then its content with `paddingLeft: 1`. A tabs section's heading lists its tabs: the current one bold in the heading colour, the others `dim`, each with its row count (`findings 3  likes 0`). The summary stats line has no heading.
- **Stats:** `gauge` (24 cells, `accent` done, `faint` rest), then each item as `value` in `text` and `label` in `dim` (`12/18 steps   3 findings`).
- **Table:** a `dim` header row; each row one line (`fit` to the width): gutter `▍` (`accent`) on the cursor row with the `selection` background, else a space; for a selectable table `○` (`dim`) or `●` (`accent`, row text brighter) after it; cells padded (widest cell, max 24) with the last column `fit` to what is left; no inline key hints (the status line has them); an empty table shows `nothing yet` in `dim` and no marks.
- **List:** state glyphs `⠼` busy, `◌` waiting (`dim`), `✓` done (`dim`), `⚑` flagged (`attention`); the cursor row as in tables; `detail` in `dim`.
- **Log:** lines in their tone (`toneColor`), `fit`, one line each.
- **KeyValue:** key in `dim` padded to 14, value in `text`.
- **Text:** wraps words (the one kind that wraps).
- **Conversation:** `you` in `dim` / the agent's messages in `text`, the question in bold `attention`, options with `›` on the picked one (`accent`), `recommended` in `dim`.

### Task 4: The agents rail

**Files:** Create `packages/view-tui/src/rail.ts`; modify `packages/view-tui/src/app.tsx` (the agents list becomes the rail); test `packages/view-tui/test/rail.test.ts`, `packages/view-tui/test/app.test.tsx`.

**Interfaces — Consumes:** `treeRows` data sources (`liveRlms`, archive rows, `Ui.agents`), Task 2 (`fit`, `gauge`). **Produces:**
```ts
/** How an agent is named on screen: a plugin agent by its id without the plugin, an RLM by its preset and id, zarg as zarg. */
export const displayName: (n: RlmNode) => string
/** Context shown dim beside a name: the plugin and the task's first words. */
export const contextOf: (n: RlmNode) => string
export interface RailRow {
  readonly id: string                // an agent id, ARCHIVED, or `archived:<id>`
  readonly depth: number             // 0 roots, 1 children, …
  readonly glyph: string             // ⠼ ✓ ✗ ■ ◆ ◇ ▸ ▾
  readonly glyphToken: ThemeToken    // accent running, dim done/stopped, error failed, attention asking
  readonly name: string              // displayName, fit to the room
  readonly note: string              // right-aligned: progress (12/18), "asks", a count, "done"
  readonly gauge?: { readonly done: number; readonly total: number } // under running agents with progress
  readonly selected: boolean
  readonly dimmed: boolean           // finished and not asking
}
export const railRows: (ui: Ui, s: SessionState, now: number | undefined, width: number) => ReadonlyArray<RailRow>
```
Rules: children indented two spaces per depth, no tree lines; folding (`▸`/`▾` before a name with hidden children, and the `+N` count as the note) and the cursor as `treeRows` does today; archived rows as today (`▸ archived N` at the end, its agents listed when open with their reason as the note). Attention rows use `◆`/`◇` by the pulse (`agentRows`' `pulse`). The note is at most 8 columns, right-aligned; the name gets `width - depth*2 - 2 - note - 1`.
