# Surfaces (plan 2 of the shell) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plugins declare where their views show (`tile`, `panel`, `popover`, `sheet`), open them as often as they like (one per agent), from code during an operator's call or declaratively from actions; the shell lays them out, caps them and routes their keys; zarg's bar is agent-zarg's own panel.

**Architecture:** `@zarg/view` gains the `Surface` schema and its checks; the SDK and the host carry and refuse surfaces like views. The host marks power calls made while the plugin handles an operator's call (`act`, `$answer`, `$message`, a slash command) as a *gesture*. The core turns surface events into three things the client already knows how to follow: persistent **panels** (an activity snapshot), **navigation requests** for tiles and sheets (a custom event), and **popovers** (items in the shared prompt queue from plan 1). The TUI draws panels at the tile area's edges, follows navigation, and shows plugin popovers and sheets with the view renderer it has.

**Tech Stack:** Bun (`mise x -- bun`), TypeScript, Effect 4 Schema, React 19, opentui 0.5.12.

**Spec:** `docs/superpowers/specs/2026-09-27-shell-sheet-design.md`, section "Surfaces: where views are shown" (plan 1, `docs/superpowers/plans/2026-09-27-shell-sheet.md`, built the rest).

## Global Constraints

- `mise run verify` before every commit; tools through `mise x -- bun …`; `mise run build:plugins` after changing a first-party plugin or the SDK (it rewrites `first-party-hashes.ts`).
- `@zarg/view`'s `.` export imports only `effect`; `@zarg/view-tui` and `@zarg/client` never import `@zarg/core` or a `/server` subpath.
- Surface kinds, exactly: `tile`, `panel` (`scope: "agent" | "shell"`, `edge: "top" | "bottom" | "right"`, `size`, `input: "none" | "onFocus"`), `popover`, `sheet`.
- Panels open any time; tiles, sheets and popovers only during a gesture (a declared `opens`, or a `Surfaces.open` while the plugin handles `act`, `answer`, `message` or one of its slash commands).
- Shell-scope panels: at most one per plugin, at most two per edge; extras wait in opening order; the operator can close any panel (it stays closed until the plugin opens it again).
- Popovers join the core's one shared FIFO queue (plan 1); nothing reorders it.
- An agent may open surfaces only for its own plugin's agents.
- Never print, log or commit a secret; never start a core or the TUI in the repo root; no live models; tests never write to `~/.config/zarg`.

## Review Focus

1. A plugin calling `Surfaces.open` for a tile from a background fiber while an unrelated `act` of the same plugin is in flight: it passes (gestures are per plugin, not per call); a background open with no call in flight is refused. → Task 2, test "an open outside any operator call is refused; one during an act passes".
2. A plugin forging `gesture: true` in its event: the host overwrites it. → Task 2, test "a plugin cannot claim a gesture".
3. A third shell-scope panel on the bottom edge while two show: it waits, and shows when one closes. → Task 6, test "a third bottom panel waits for a free place".
4. A plugin whose agent ends while its panel and popover are up: both go (panel from the snapshot, popover from the queue). → Task 4, test "an agent's end closes its panels and withdraws its popovers".
5. Replaying an old log (a restarted TUI) does not jump the view to a tile some plugin opened an hour ago. → Task 5, test "an old navigation request is not followed".

```ts
// packages/view/src/surfaces.ts
import { Schema } from "effect"
import { Surface } from "./schema"

export const surfacesProblem = (surfaces: unknown, views: ReadonlyArray<string>): string | undefined => {
  if (surfaces === undefined) return undefined
  if (!Array.isArray(surfaces)) return "surfaces must be a list"
  const names = new Set<string>()
  for (const raw of surfaces) {
    const r = Schema.decodeUnknownExit(Surface)(raw)
    if (r._tag !== "Success") return `surface ${String((raw as { name?: unknown } | null)?.name)} does not fit any kind (tile, panel, popover, sheet)`
    const s = r.value
    if (!/^[a-z][a-z0-9-]*$/.test(s.name)) return `surface name "${s.name}" must be kebab-case`
    if (names.has(s.name)) return `surface ${s.name} is declared twice`
    names.add(s.name)
    if (!views.includes(s.view)) return `surface ${s.name} shows view ${s.view}, which the plugin does not declare`
    if (s.kind === "panel" && (!Number.isInteger(s.size) || s.size < 1 || s.size > 40)) return `panel ${s.name}: size must be a whole number from 1 to 40`
  }
  return undefined
}
```

```ts
export const PANELS = "zarg.panels"          // ACTIVITY_SNAPSHOT, messageId `${thread}:panels`, content { panels: PanelInstance[] }
export const NAVIGATE = "zarg.navigate"      // CUSTOM, value { kind: "tile" | "sheet", view: string, at: number }
export interface PanelInstance { readonly id: string; readonly plugin: string; readonly agent: string; readonly view: string; readonly name: string; readonly scope: "agent" | "shell"; readonly edge: "top" | "bottom" | "right"; readonly size: number; readonly input: "none" | "onFocus" }
export const makeSurfaces: (log: ThreadLog, threadId: string) => {
  readonly openPanel: (p: PanelInstance) => void      // id = `${plugin}:${name}:${agent}`; replaces one with that id
  readonly closePanel: (id: string) => void
  readonly closeAgent: (agent: string) => void         // every panel of that agent
  readonly navigate: (kind: "tile" | "sheet", view: string) => void
  readonly announce: Effect.Effect<void>               // an empty snapshot: a new core's panels start from nothing
}
/** The view store key of an agent's view: the agent id for the view it started with, `${agent}@${view}` for another. */
export const viewKey: (views: ViewStore, agent: string, view: string | undefined) => string
// prompts.ts: a popover item
readonly show: (item: { readonly plugin: string; readonly agent: string; readonly view: string; readonly title: string }) => Effect.Effect<string> // id
readonly close: (id: string) => Effect.Effect<{ readonly notice: string }>
readonly closeAgent: (agent: string) => Effect.Effect<void>
// CUSTOM zarg.prompt value for a popover: { id, kind: "surface", question: title, options: [], view, agent }
```
`pluginAgents(log, threadId, layoutOf, surfaceOf, surfaces, prompts)` — `surfaceOf(plugin, name): Surface | undefined`.

**Event handling** (`plugin-agents.ts`), for a plugin agent id `${plugin}:${e.id}`:
- `set` / `append`: `views.set(viewKey(views, id, e.view), …)`; a key not started yet is started with `layoutOf(plugin, e.view)` first (a panel's data may arrive before the panel opens).
- `open` (`{ surfaces: [{ surface, agent, focus? }], gesture }`): for each, `const s = surfaceOf(plugin, surface)`; refuse (throw, so the plugin's call fails) when the surface is not declared, when `agent` is not a valid id, or when `s.kind !== "panel" && e.gesture !== true` (`"<surface> is a <kind>: it opens only while you handle the operator's call; ask for attention instead"`). Make sure the key's view store entry exists (as for `set`). Then: panel → `surfaces.openPanel`; tile / sheet → `surfaces.navigate(kind, key)`; popover → `prompts.show({ plugin, agent: id, view: key, title: layoutOf(plugin, s.view)?.name ?? surface })`.
- `close` (`{ surface, id }`): panel → `closePanel(\`${plugin}:${surface}:${id}\`)`; popover → the open prompt for that agent and view closes; tile / sheet → nothing (navigation is one-way).
- `end`: `surfaces.closeAgent(id)` and `prompts.closeAgent(id)`, then what `end` does today.

**Actions with `opens`** (`actions.ts`): `makeActions` gains `opensOf: (agent: string, action: string) => ReadonlyArray<{ surface: string; agent?: string }> | undefined` and `open: (plugin: string, surfaces: ReadonlyArray<{ surface: string; agent: string }>) => void` (live.ts wires them to the view store's layout and to `pluginAgents(…)(plugin, { event: "open", surfaces, gesture: true })`). `act`: when the action declares `opens`, open them (an `agent` in `opens` is within the same plugin; default the acting agent) and answer `{ notice: "opened" }` without calling the plugin. Otherwise as today.
